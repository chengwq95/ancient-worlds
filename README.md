# Ancient Worlds

A collection of bilingual interactive pages about ancient civilizations, mythology, cities, writing systems, cultural history, and everyday life.

## Read online

| World | Description | Read | Source |
| --- | --- | --- | --- |
| **Ancient Egypt** | A long-form guide to gods, pharaohs, pyramids, mummies, hieroglyphs, the Nile, and daily life in ancient Egypt. | [Read](https://ancient-egypt-stories.pages.dev/) | [Source](https://github.com/chengwq95/ancient-egypt) |
| **Ancient Mesopotamia** | A guide to Sumer, Akkad, Babylon, Assyria, city-states, cuneiform, Hammurabi's Code, gods, myths, and river civilizations. | [Read](https://ancient-mesopotamia-stories.pages.dev/) | [Source](https://github.com/chengwq95/ancient-mesopotamia) |
| **Ancient Greek** | A visual atlas of Greek gods, heroes, monsters, myths, temples, symbols, stories, and cultural memory. | [Read](https://ancient-greek-stories.pages.dev/) | [Source](https://github.com/chengwq95/ancient-greek) |

## About this collection

This repository is a simple directory for the ancient-world pages above. Each project remains independently developed and hosted in its own repository.

Want to read locally? Clone any project repository and open its `index.html` file in a browser.
